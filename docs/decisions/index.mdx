# Architecture Decisions

ADRs in this repo record public package/API decisions. Repo-boundary migration
ownership decisions are tracked in internal governance.

## Index

| ADR | Title | Status |
| --- | --- | --- |
| [0001](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0001_world_sync_over_convergence_kernel.md) | ecsly world sync consumes the convergence kernel; parents choose strategies, the kernel never learns about worlds | Accepted |
| [0002](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0002_live_world_delta_bridge.md) | the live World→delta bridge exists as `ecsly_world_sync_bridge`; structure syncs as keyed state, and the driver owns anti-entropy | Accepted |
| [0003](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0003_world_zones_seamless_travel.md) | zone travel for ecsly worlds — the mesh pulse is an ordinary system (the game's own scheduler drives it), interest policies stay game-side | Accepted |
| [0004](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0004_convergence_session_adoption.md) | world sync adopts the convergence session core; the bridge sheds its own anti-entropy stack (driver/message/transport deleted; watermark correctness lands once, in the foundation) | Accepted |
| [0005](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0005_high_performance_ecs_engine_positioning.md) | ecsly is a high-performance Dart ECS engine; public docs claim exactly what the artifacts prove (voice rules, evidence freshness, North Star amendment) | Accepted |
| [0006](https://github.com/Arenukvern/ecsly/blob/main/docs/decisions/0006_append_rows_bulk_data_plane_ingest.md) | `World.appendRows` — append-only data-plane ingest becomes a first-class runtime path (immediate bulk row reservation with the full structural invariants; measured against the command queue and plain maps at 1k/100k/1M) | Accepted |
